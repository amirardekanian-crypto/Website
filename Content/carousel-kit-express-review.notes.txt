data-bg patterns: NONE of the 23 templates in the template-library section actually carry a data-bg="..." attribute (checked via grep across the source file — data-bg only appears inside CSS attribute-selectors, never as a live HTML attribute on any post-canvas/slide div). So the entire "BACKGROUND PATTERNS" CSS block (grid/dots/scanlines/diagonal/glow/frame/corner) was dropped as unused, including the data-bg="glow" color-mix() rule mentioned as a risk in the spec — moot since it's never referenced.
