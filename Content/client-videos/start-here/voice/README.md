# Amir's voice recordings go here

Upload the recordings of the "Start here" video into **this folder** (`Content/client-videos/start-here/voice/`) on the branch **`claude/vibrant-davinci-8ps44e`**.

**How (on a computer):** open the repo on GitHub, switch the branch to `claude/vibrant-davinci-8ps44e`, open this folder, then **Add file → Upload files**, drop the audio files, and under *Commit changes*
choose **Commit directly to the claude/vibrant-davinci-8ps44e branch**. Then tell Claude "uploaded".

**Names:** `1.m4a`, `2.m4a` … one file per beat of the script (if a second take is better, `1b.m4a`). Any format is fine (.m4a, .wav, .mp3).

**Also send the text you actually said** (paste it in the chat) if it differs from the approved script even by one word. Claude cannot turn Farsi speech into text here, so the subtitles come from your text, not from the audio.
