# 11. Tidy the roster, No video yet (2026-11-23)

Two small things Amir asked for. Live data at the time: 24 of 45 people with a programme had not finished a session in 28 days (9 never), nobody had ever been marked paused or former, and 72 of 212 exercises in the current cycles had no video.

- **Tidy up (Athletes, above the roster).** A quiet fold, `<details id="tidyFold">`, drawn by `tidyFoldHtml()` only when `tidyCandidates()` has someone: `N haven't trained in 4 weeks · tidy up`. A candidate is in `S.ath`, coached tier, has a programme, is not `demo` or `AMIR_ATHLETE_ID`, has status active, and has a `lastSession` that is null or more than 28 days ago. Oldest session first, never-trained last. A row: face, name (opens the file), `last session <date> · <tier>` or `never trained · <tier>`, plus `cycle ended/ends <date>` when the programme has a dated cycle, then **Paused**, **Former** and a quiet **Keep active**. Paused and Former call `setAthleteStatus()`, the same save the File's Status panel uses (no note passed), so its refusals and its `refetch(['status'])` apply, and `reasonsOf()` and `inTotals()` are untouched. **Keep active** writes `localStorage['coach.tidyKeep'] = { id: 'YYYY-MM-DD' }` and hides that person for 28 days on this device only (every read and write is in try/catch; no storage means nothing is hidden). The fold's open state is `_tidyOpen`, set from its `toggle` event. Free-tier people are left out: they use habits, not sessions.
- **No video yet (Exercises, Coverage, after the summary panel).** `<section class="panel" id="noVideo">`: an approved Spine entry that at least one live programme card uses (the same `who` map Coverage counts with, circuit items included) and that has no `video`, most athletes first, then name. Entries whose pattern is `conditioning` sit in a folded `Cardio (probably no video needed) · N`. A row has a `type="url"` box and **Save**. `noVideoSave(id)` checks `^https?://`, then calls `coach_save_spine()` with `p_entry = { video }`, `p_entry_snap = { video: <what the page read> }` and empty coach halves: one column, guarded by the snapshot like the editor's Save. On success the entry's copy in `S.spine` gets the link and the row leaves; a refusal (someone else changed the video) names it with `fail()`. Typed links live in `_nvDraft` across redraws.
- **Entries chip.** `No video · N` beside Drafts and Approved lists the same set (`filter === 'novideo'`), so a row can be opened in the editor.
- **Tests.** `scripts/headless/coach/run.js`: `roster-tidy`, `roster-tidy-none`, `exercises-no-video`; the seed is `buildSeed({ tidy: true })` (`tidySeed()` in fixtures.js).
